# Keystone

Keystone locks a brand's visual direction as a reusable Style DNA, then generates every brand image from that DNA so the results stay on-brand.

## Projects and directions

**项目 (Project)**:
One brand or product a user is working on, from its brief through its style lines and generated images.
_Avoid_: 工程, workspace

**项目文档 (Project Document)**:
The server-held, authoritative record of a Project's full state: brief, intent, direction candidates, style lines with their revs and slot images.
_Avoid_: 本地项目, project cache

**方向候选 (Direction Candidate)**:
One proposed visual direction for a Project, shown as a preview board, before the user locks it.
_Avoid_: 预设, option

**锁定 (Lock)**:
Choosing one Direction Candidate to become the Project's active Style Line; the others become standby lines.
_Avoid_: 选择, confirm

## Style

**风格 DNA (Style DNA)**:
The structured description of a visual system: palette, light, material, geometry, density, type mood, mood words, forbidden styles and prompt text.
_Avoid_: 风格卡, theme, preset

**风格线 (Style Line)**:
An evolving line of Style DNA within a Project, holding its own Style Revs and slot images; one line is active, others are standby or archived.
_Avoid_: 分支, branch, 风格

**风格版本 (Style Rev)**:
One numbered, immutable snapshot of a Style Line's DNA, with the rev it came from and a change note.
_Avoid_: 风格历史, version

**写回 (Writeback)**:
Merging an edit instruction into the current Style DNA to create a new Style Rev, so later images carry the change.
_Avoid_: 保存风格, promote

**分叉 (Fork)**:
Starting a new Style Line from a chosen Style Rev of an existing line.
_Avoid_: 复制风格, branch

**归档 (Archive)**:
Retiring a Style Line from the active and standby set while keeping it restorable.
_Avoid_: 删除风格

## Images

**物料槽 (Slot)**:
A kind of brand deliverable a Style Line produces images for, such as the product flagship screen, key visual or website hero.
_Avoid_: 模板, asset type

**采用 (Adopt)**:
Marking one image rev as the chosen image for a Slot on a Style Line.
_Avoid_: 选定, select
