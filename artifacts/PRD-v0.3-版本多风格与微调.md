# 需求修订稿 v0.3：版本记录 · 多风格 · 生成后微调

> 相对 v0.2 的增量，不推翻：独立工具、出高保真图、不出码、锁定后不漂优先。  
> 新增三条能力：版本记录、一个项目里可保留不同风格、生成后的图可微调。

---

## 0. 相对 v0.2 新增了什么

| 新增 | 含义 | 不做成什么 |
| --- | --- | --- |
| 版本记录 | 风格决策和图修改都可回看、对比、回退 | 不是 Git，不做整项目一键回到上周 |
| 不同风格 | 一个项目可并存多条风格线 | 不是同时往一张画布里混着生 |
| 生成后微调 | 对已生成的那张高保真图做有限修改 | 不是 Photoshop，不拆图层精修 |

三条共用一条总规则：

1. **版本只追加，不覆盖。**
2. **项目可多风格，当前工作风格只能有一个。**
3. **微调默认只改这张图；写回才改风格。**

「不漂」的粒度从「整个项目一张脸」改成 **单条风格线内部不漂**。多风格是为了比较和留后路，不是把 A 的色涂到 B 的图上。

## 1. 对象模型

```
Project  一个想法 / 一个品牌探索
├── StyleBranch  风格线 A / B / C（可并存）
│     ├── StyleRev  这条线的 DNA 版本：rev1 锁定 → rev2 更密
│     └── Asset     物料槽里的一张「图」
│           └── ImageRev  这张图的生成与微调链：v1 原图 → v2 更暖
```

| 对象 | 用户怎么叫 | 何时产生 |
| --- | --- | --- |
| 风格线 StyleBranch | 「极简商务」「年轻活力」 | 段 1 锁定，或从备选升级，或从现有线开分支 |
| 风格版本 StyleRev | A · rev2 | 首次锁定、风格滑杆写回、从一张图「提升为风格」 |
| 物料 Asset | KV-01、旗舰页、官网首屏 | 在某条风格线下选择物料槽出图 |
| 图版本 ImageRev | KV-01 · v3 | 每次生成或微调都新增一版，旧文件保留 |

生成时把当时的 `(style_id, rev)` 冻在 Asset / ImageRev 上。后面 DNA 改了，旧图不会自动变脸。

## 2. 多风格怎么放进现有两段式

段 1 仍然一次出 4 个方向差够大的候选。变化在锁定时：

- 点选的那张成为 **当前工作风格**
- 其余 3 张不删，进 **备选风格**
- 用户可以把备选「升级为正式风格线」，或以后再回来开分支
- 「再开一条风格」走回 4 宫格，只新增一条线，已有图全部保留

段 2 出图前必须先选当前风格线。同一时刻只有 1 条线在出图。这是防串味的前提。

MVP 上限：一个项目最多 3 条风格线（1 条当前 + 2 条备选）。再开新线需先归档一条。不做无限分支树，也不做两个风格自动合并。

用户能读懂的命名：

- 风格线：「极简浅色」「商务深色」
- 风格版本：「极简浅色 · v2（更暖）」
- 图版本：「官网首屏 · v3（去左上装饰）」

允许的对比：

- 同一物料槽、两条风格线并排（两边都是 KV，或两边都是旗舰页）
- 禁止拿 A 的海报对 B 的设置页

从 A 派生「更暖的 A」= 同一风格线的新 StyleRev。  
从 A 觉得该走另一条路 = 新 StyleBranch。  
这两件事在界面上要分开，不能都叫「再生成」。

## 3. 版本记录

工作台右侧两条时间线，用 Tab 切开，不要合成一本糊涂账。

### 3.1 图版本

当前这张图：v1 首次生成 → v2 更暖 → v3 换构图。

每条记录显示：缩略图、时间、动作类型、一句话 diff。  
点缩略图回看；点「设为当前采用」才换采用稿。

### 3.2 风格版本

这条风格线：rev1 锁定 → rev2 更密 → rev3 去渐变。

每条记录显示：Style Bible 缩略、改了哪一轴、从哪到哪。  
回退风格只移动 `current_rev` 指针。已采用的旧图保持原快照，并标记「生成时用的是 revX」。

### 3.3 回退边界

| 动作 | 影响 | 不影响 |
| --- | --- | --- |
| 回退图版本 | 当前物料的采用稿指针 | 风格 DNA、其他图 |
| 回退风格版本 | 之后新出的图 | 已经采用的旧图 |
| 切换风格线 | 工作上下文、图集过滤 | 另一条线上的任何文件 |
| 整项目回到上周 | P2 再议 | MVP 不做 |

删除风格线默认归档，不是真删。

顶栏始终显示三件事，避免改错层：

`当前风格线 · 当前风格版本 · 当前图版本`

例如：`极简商务 · A rev2 · 官网首屏 v3`

## 4. 生成后微调

作用对象是 **已经生成的那一张图**。面板从选中图右侧滑出。

面板顶部锁死两个出口：

| 出口 | 默认 | 留下什么 |
| --- | --- | --- |
| 只改这张图 | 是 | 新 ImageRev，Style DNA 不动 |
| 写回风格，影响以后出图 | 否，二次确认 | 新 StyleRev；旧图保留；是否切换 current_rev 再问一次 |

### P0 微调（MVP）

- 构图变体：换构图 / 主体更大 / 更留白
- 风格贴合：更像当前风格卡
- 滑杆：明暗、冷暖、对比、饱和、颗粒/质地（小步）
- 一句局部指令：去杂物、背景更干净、标题更克制
- 每次出 1–2 张新 ImageRev，左侧钉原图对照

### P1

- 局部涂抹重绘
- 改图上文字
- 换背景
- 参考另一张已采用图靠拢

### 明确不做

- 图层、笔刷、印刷级精修
- 一条指令同时改两条风格线
- 微调时偷偷改 current spec、覆盖原文件

### 何时必须升 StyleRev

- 用户明确点「写回风格」
- 滑杆累计超过阈值（色相偏太多、密度换档、材质换家族）
- 连续两张图级修改都在改同一轴，提示「要不要写回，免得以后还要改」

写回流程：抽出这张图和当前 spec 的 diff → 生成 StyleRev+1 → 默认不自动把工作版本切过去，避免误伤后面出图。

## 5. 四个入口，避免互踩

| 用户想法 | 该用的入口 | 留下的版本 |
| --- | --- | --- |
| 这张有点暗 | 图微调，不写回 | 新 ImageRev |
| 以后都不要这么花 | 写回风格 | 新 StyleRev，旧图保留 |
| 想看看另一条路 | 开新风格线，或把备选升级 | 新 StyleBranch |
| 刚才那版更好 | 时间线「设为当前」 | 只移动指针，不删历史 |

危险操作二次确认：换风格线出图、写回 DNA、归档风格线。

## 7. 验收补丁

1. 同一张图微调 5 次，第 1 版仍在，时间线可点回去。
2. 项目里同时有 2 条风格线，出 KV 时不会串用另一条的色和材质。
3. 「只改此图」后再出下一张，下一张不带这次图级修改。
4. 「写回风格」后再出下一张，下一张带上该轴变化；旧的已采用图不变脸。
5. 回退 style rev 后，新图回到旧气质，已采用图仍是原样，并标着当时的 rev。
6. 4 宫格里没被锁定的方向仍能在备选里找回，不会在锁定瞬间丢掉。
7. 顶栏能看出自己在改风格线、风格版本，还是某一张图。

成功标准仍服从 Q5：单条风格线内部，锁定后下一张必须像同一品牌。多风格是比较装置，不是放松一致性。

额外三条：

- 图级微调之后，这张图仍像当前风格线，不能微调成另一张脸
- 1 次回退能回到上一采用稿
- 两条风格线分别出 KV，色和材质不串味

## 8. 和 v0.2 主流程怎么接

```
段1 定方向
  4 候选 → 锁定当前工作风格
  其余进备选（不同风格被保留）

段2 出图工作台
  先选风格线 → 再选物料槽 → 出高保真图
  对当前图微调 → 新 ImageRev
  必要时写回 → 新 StyleRev
  两条时间线可回看 / 对比 / 设为当前
  下载时按「当前采用稿」打包，历史版可选打进 zip
```

用户带走的还是高保真图 + 风格卡。现在图集里可以带：

- 同一风格下的多张物料
- 同一张图的采用版（可附带关键历史版）
- 若用户要比较，可额外导出「风格 A vs 风格 B」对照图

仍然不出码。
