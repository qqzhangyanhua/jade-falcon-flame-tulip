# 需求修订稿 v0.2：风格锁定 + 高保真出图

> 独立工具。先锁定视觉方向，再按同一套视觉 DNA 出高保真图。  
> 对外交付是图。对内防漂靠 Style Spec + 锁定参考图。  
> 品牌视觉先做气质和应用，不做 Logo / VI 工程。

---

## 0. 拍板纪要

| 问题 | 结论 | 对需求的影响 |
| --- | --- | --- |
| Q1 独立工具还是嵌入模块 | 独立工具 | 自有项目、选风格、出图、图集、下载闭环 |
| Q2 生成对象 | 品牌视觉都要 | 一次锁定同时服务 UI、官网、品牌主视觉，但 MVP 必须收口 |
| Q3 选完下一步 | 出高保真图片，不出码 | 主路径改成出图工作台；CSS / Figma / 代码退出 P0 |
| Q4 既有品牌资产 | 无 | 默认探索模式，不做品牌约束 diff |
| Q5 好看 vs 不漂 | 锁定后不漂为准 | 候选图差异要大，锁定后一致性验收看跨品类图 |
| Q6 预览形态 | 未答 | 建议：对外始终给高保真图；对内用 Style Spec + 风格参考图硬约束 |

## 1. 一句话定位

没有品牌资产的人，丢一张原型或一段描述进来，先选出视觉方向，再在同一方向下持续生成看起来像同一个品牌的高保真图。

这不是文生图广场，也不是出码工具，也不是 Logo 工厂。

```
想法 / 原型
    → 4 个方向候选
    → 锁定视觉 DNA
    → 按画面类型出高保真图
    → 下载图集 + 风格卡
```

---

## 2. 目标与非目标

### 目标

- 3 分钟内完成一次风格锁定
- 一次锁定同时覆盖产品界面和品牌主视觉
- 锁定后换画面类型，新图仍像同一品牌
- 用户带走：高保真图集 + 一张给人看的风格卡

### 非目标

- 不出代码、不接 v0 / Cursor、不做 Figma 组件库
- 不做 Logo 精修、完整 VI 手册、包装刀版、印刷规范
- 不像素级复制竞品
- 不让用户为 UI 和品牌各选一套风格
- 不做 Midjourney 式命令行
- 不把 JSON token 当用户主交付

---

## 3. 品牌视觉怎么收口

「品牌视觉都要」按传统 VI 会变成 Logo、辅助图形、海报、包装、名片、社媒、UI、手册。MVP 全做会炸。

拆三层，先做气质，再铺物料，最后才碰标志。

| 层 | 内容 | 何时做 |
| --- | --- | --- |
| L0 气质层 | 风格候选、品牌主视觉 KV、产品旗舰页高保真、延展 1 张（官网首屏或社媒封面） | MVP |
| L1 物料层 | 海报、社媒套图、包装效果图、官网内页、App 第 2/3 屏 | V1 |
| L2 识别层 | Logo 系统、VI 手册、字体精修、刀版 | V2，谨慎 |

原则：**先锁「看起来像谁」，再铺「用在哪」，最后才做「标志是什么」。**

MVP 只开三个物料槽，共用一次锁定：

1. **产品界面旗舰页**：有原型则保结构升保真；没原型则按需求出 1 张代表界面（App 或 Web 由输入推断）
2. **品牌主视觉 / KV**：同色、同材质、同气质；构图可以完全不同
3. **延展 1 张**：官网首屏或社媒封面，进工作台时勾选。默认建议官网首屏，和产品界面更连得上

## 4. 目标用户与场景

独立工具，第一用户仍是没有设计师、也没有现成品牌资产的人。

1. 独立开发者 / 创始人：要路演、要先发内容、要让产品和品牌看起来像一家
2. 产品经理：有线框，但界面气质和对外视觉对不上
3. 内容 / 运营兼职品牌的人：要出 KV、封面、首屏，但不会定调

设计师不是第一用户。无既有品牌色、Logo，不走「品牌资产库」路径。

### 场景 1：只有一句话想法

- 前置：品类 + 受众 + 想传达的感觉
- 动作：选出风格 → 出 KV + 产品氛围界面 + 一张延展
- 后置：下载图集，用于路演、招募、先发内容

### 场景 2：已有线框，界面和品牌对不上

- 前置：上传原型 + 一句品牌气质
- 动作：结构跟原型，气质跟锁定风格；出旗舰页高保真 + 匹配的 KV
- 后置：给团队看「产品长这样，品牌也长这样」

### 场景 3：先有一张满意的图，还要下一张

- 前置：已锁定 style_id
- 动作：选画面类型，补一句内容，直接出
- 后置：新图必须一眼能认成同一品牌；失败只重出这一张，不重锁风格

### 场景 4：方向对了但差一口气

- 前置：已锁风格 A
- 动作：只调一个轴（更冷、更疏、更亮、更产品感）得到 A2
- 后置：A / A2 可回退，后续出图跟当前 rev

## 5. 两段式主流程

不要做成一个无限画布，也不要选完就结束。

### 段 1 · 定方向（约 3 分钟）

1. 新项目：文字需求 和/或 原型图，可选参考图
2. 解析槽位并轻量确认（品类、受众、平台、禁忌；可跳过）
3. 出 4 张候选：同一主题，风格象限必须拉开
4. 单选 / 双选融合 / 按维度微调
5. 锁定确认卡：同时出示 **一张界面预告 + 一张品牌 KV 预告**  
   避免用户只按「海报好看」选了不适合产品界面的风格
6. 确认后落库：style_id、Shared Visual DNA、锁定参考图、内部 Style Spec

### 段 2 · 出图工作台（锁定后的主界面）

```
左：已锁 Style Card（色条、气质词、当前 rev）
中：当前高保真图 + 与上一张已采用图的对照
右：物料清单 + 已采用图集
底：物料类型（单选）+ 一句内容（产品名 / 卖点 / 活动名）
```

- 风格字段只展示「已锁定」，用户在出图阶段改的是内容，不是风格
- 每次出图默认 2 张同风格、不同构图的变体
- 用户点「采用」进入项目图集
- 「换风格」是危险操作：二次确认，并说明已采用的图不会自动重做

### 页面结构

- 新项目（输入）
- 选风格
- 出图工作台
- 项目图集
- 下载（单张 / 整包 zip：PNG/JPG + 风格卡预览图）

## 6. 输入规则

| 输入 | 段 1 作用 | 段 2 作用 |
| --- | --- | --- |
| 文字需求 | 抽品类、受众、情绪、禁忌 | 变成各物料槽的内容底稿 |
| 原型图 | 只当结构参考，不当风格参考 | 仅产品界面槽用来升保真 |
| 参考图 | 只当风格线索 | 不锁别人的版式当结构 |
| 竞品精美海报 | 系统要问：结构参考还是风格参考？默认风格参考 | — |

无既有品牌资产：不提供「上传 Logo / 品牌色强制跟随」。用户若随口说「用蓝色」，记入意图层，不当成已注册品牌色系统。

含糊词（高级、好看、有质感）在段 1 译成滑杆：明暗、饱和、留白、圆角感、材质。

## 7. 一次锁定如何同时管 UI 和品牌图

用户不锁两次。锁定的是视觉 DNA，不是某一张构图。

### 7.1 共用层 Shared Visual DNA

全品类生效：

- 色板（主色 / 辅色 / 背景 / 强调）及大致使用比例
- 明暗与对比
- 材质与光感：flat / paper / film / studio-soft / hard-flash
- 气质词 + 禁止项
- 图形语言：几何干净 / 有机 / 纹理 / 留白
- 字体气质：几何无衬线 / 人文衬线 / 圆体（不绑商用字体文件）
- 锁定参考图 1–2 张（用户选中的候选，后续出图必须当 style ref）

### 7.2 品类层 Type Overlay

同一 DNA，不同版式约束：

| 物料 | 额外锁什么 | 不锁什么 |
| --- | --- | --- |
| 产品界面 | 结构（来自原型）、密度、圆角、卡片分割、导航气质 | 海报式大构图 |
| 品牌 KV | 主体占比、留白、光线方向、可否出人物/产品特写 | 原型里的模块结构 |
| 官网首屏 / 社媒封面 | 信息层级：主标题 / 卖点 / 主视觉位置 | 与 KV 抢同一构图 |

生成公式永远是：

`Shared DNA + 当前品类 overlay + 这次要的内容`

禁止只追加一句「保持同样风格」。

## 8. 内部 Style Spec（用户不必看见 JSON）

对外是图。对内必须落库，否则下一张必漂。

最小结构：

```json
{
  "style_id": "sty_xxx",
  "rev": 1,
  "shared_dna": {
    "name": "冷静留白",
    "one_liner": "浅色、克制、适合工具产品和品牌主视觉共用",
    "colors": {
      "bg": "#F7F8FA",
      "surface": "#FFFFFF",
      "text": "#1F2937",
      "primary": "#2563EB",
      "accent": "#0EA5E9"
    },
    "light": "studio-soft",
    "material": "flat-paper",
    "geometry": "rounded-comfortable",
    "density": "airy",
    "type_mood": "geometric-sans",
    "mood": ["calm", "trustworthy"],
    "forbidden": ["neon", "cyberpunk", "heavy-gradient", "clutter"]
  },
  "anchors": {
    "style_ref_images": ["candidate_03.png"],
    "style_bible_image": "bible_sty_xxx_r1.png"
  },
  "overlays": {
    "ui": { "radius_md": 10, "card": "outlined", "nav": "top-light" },
    "kv": { "subject_ratio": "medium", "whitespace": "generous" },
    "hero_or_cover": { "title_weight": "high", "cta": "visible" }
  },
  "prompt_pack": {
    "positive": "clean light studio, restrained blue accent, generous whitespace, quiet luxury utility",
    "negative": "neon, cyberpunk, noisy collage, skeuomorphism, cluttered widgets"
  }
}
```

锁定当下还要内生一张 **Style Bible 图**（色块 + 材质 + 字体气质 + 一枚应用缩略），作为后续出图的第二张参考锚点。

用户侧只看到风格卡：风格名、一句话、色条、气质词、Do / Don't、反例。

## 9. 功能需求

### P0

- F1 文字需求输入与槽位抽取
- F2 原型图上传与结构解析（线框 / 草图 / 截图）
- F3 4 张正交风格候选；确认卡同时出界面预告 + KV 预告
- F4 单选锁定 / 双选融合 / 维度微调
- F5 锁定后落 Shared DNA + 参考图 + Style Bible
- F6 出图工作台：三个物料槽，每次 2 张变体，可采用进图集
- F7 跨槽抽检：采用后必须再出另一槽，并问「像同一个品牌吗」
- F8 下载：高保真图 + 风格卡预览图

### P1

- F9 延展槽在官网首屏 / 社媒封面之间切换
- F10 海报、第二屏 UI、社媒套图（3 张同一活动）
- F11 风格 rev 与回退；小步滑杆只改被点名的轴
- F12 参考图 / 结构图分槽上传
- F13 「更像锁定卡 / 更干净 / 换构图保留气质」三键返工

### P2

- F14 包装效果图、更多页面
- F15 Logo / VI（单独评估，不默认做）
- F16 团队投票、分享链接评审
- F17 品牌资产库（与当前「无既有资产」设定相反，后置）

## 10. 交互要点

### 选风格

- 4 宫格并排，不左右滑
- 第一轮方向差必须大；第二轮才出近似变体
- 每张候选旁写：气质一句话、可能偏离需求的点、适不适合既做界面又做主视觉
- 确认页拆两个判断：**喜欢这张图** / **适合我的产品与品牌**
- 只按好看选、但界面预告明显不可用时，提示风险，不禁止锁定

### 出图

- 物料类型是单选按钮，不是自由 prompt
- 用户只填内容：产品名、卖点一句、活动名
- 左侧常驻上一张已采用图，新图出来立刻对照
- 「不像」时高亮可能漂的轴（色走暖、材质变了、明暗反了），只修那一轴
- 图集用同一浅底或深底对齐展示，不瀑布流乱铺

### 原型图的角色要切开

- 段 1：结构参考
- 段 2：只进入产品界面槽
- KV 槽禁止复用原型构图，只复用 DNA

## 11. 防漂技术约束

探索和量产不是同一套管线。

| 阶段 | 目标 | 约束强度 |
| --- | --- | --- |
| 探索 | 4 个方向差够大 | 低一致性，高多样性 |
| 固化 | 抽出 DNA、embedding、Style Bible | 用户一锁就做，不等下一张 |
| 生产 | 每张高保真图都像同一品牌 | 高一致性 |

生产图必须同时带：

1. 锁定候选图和/或 Style Bible 做 style reference（中高权重）
2. 有原型的界面图加结构控制（线框 / Canny），只换皮肤
3. Prompt Pack：正向 + 负向 + 色码 + 光感词
4. 同一 style_id 的 seed 族或 embedding，保证可复现

连续 2 张抽检不合格：降低创意温度、提高 ref 权重，而不是换一套词重新抽风格。

MVP 不训 LoRA。V1 再考虑对用户锁定图集做轻量 style adapter。

内部一致性裁判（用户不可见）：

- 主色能否在锁定色板中找回（ΔE 超阈值失败）
- 明暗方向一致（不能一张浅底一张赛博黑）
- 材质 / 光感一致（不能一张扁平插画一张电影摄影）
- 与锁定参考图的 style embedding 距离低于阈值
- 命中 forbidden 即失败

## 12. 验收与成功标准

交付物是图，所以主验收看图。Style Spec 是内部手段。

### 功能验收

1. 仅文字或仅原型，都能完成锁定
2. 4 张候选主色相、材质、明暗必须拉开
3. 锁定后连出 UI 旗舰页、品牌 KV、延展页 3 张
4. 三张放一起，主色 / 明暗 / 材质 / 气质同属一套
5. 有原型的 UI 图不因换风格丢模块
6. 「不像」只重出当前张或只调一轴，不强制重选风格
7. 下载包里有高保真图和风格卡，没有代码文件作为主产物

### 产品指标

| 指标 | 目标 |
| --- | --- |
| 首次锁定时长 | ≤ 3 分钟 |
| 跨品类「同一品牌」主观分 | 4 分制 ≥ 3 |
| 推倒重选风格的比例 | 明显低于直接文生图基线 |
| 单张返工次数 | 可接受；整套推倒不可接受 |
| 「这张更好看但换品牌了」的误用 | 用确认卡双问题追踪 |

不再把 token 导出率、代码粘贴率当主指标。

## 13. 独立工具的产品闭环与付费

闭环四步：丢想法 → 选方向 → 锁风格 → 出高保真图并下载。

付费卡在两处，不要只按张数卖：

1. 锁定风格：把这次决策存成可复用的 Visual System
2. 在同一系统下继续出高保真图

套餐按画面包：

- 启动包：KV + 旗舰页 + 1 张延展
- 延展包：同一 style_id 再出 N 张指定类型

不要拆成「UI 产品」和「品牌产品」两个 App，那会把一次锁定拆碎。

免费体验建议：1 次风格探索 + 4 张候选 + 1 张带水印高保真预览。

## 14. 竞品错位

| 类型 | 代表 | 缺口 |
| --- | --- | --- |
| 通用生图 | Midjourney、即梦、Firefly | 单张可以很好看，下一张不像一家 |
| Logo 套件 | Looka、Brandmark | Logo 先行，弱于按原型锁结构，也弱于先定气质 |
| 出界面 / 出码 | v0、Stitch、Figma Make | 不做品牌主视觉，风格决策不是主任务 |
| 品牌一致性出图 | Brandiseer、Lovart、Kive | 多半要求已有品牌资产；我们默认从零探索再锁定 |

本产品卖的是中间层：没有品牌资产时先锁定视觉 DNA，再让 UI 图和品牌图共用它，持续出高保真图。

## 15. 分期

**MVP**

- 独立项目空间
- 双输入 → 4 候选 → 双预告确认卡 → 锁定
- 三个物料槽出高保真图
- 图集、对照、单张返工、下载图 + 风格卡

**V1**

- 海报、社媒套图、第二屏 UI、包装效果图
- 风格 rev / 回退
- 更稳的 style ref 与一致性裁判
- 分享链接给别人看齐性

**V2**

- Logo / VI（单独论证）
- 团队协作
- 已有品牌资产的约束模式
- 视频主视觉（若仍要「品牌视觉都要」的动态层）

## 16. 仍待确认（不阻塞开发草案）

1. 延展槽默认做官网首屏，还是社媒封面？建议官网首屏。
2. 产品界面默认优先 App 还是 Web？建议跟输入走：有手机原型出 App，否则出 Web 首屏。
3. 高保真图分辨率与比例：KV 默认 4:5 或 16:9？界面跟设备走？
4. 风格卡要不要做成一张可发群里的长图（色板 + 三张应用缩略）？建议要，便于对齐，仍不出代码。
5. Q6：探索阶段的 4 张候选是否直接上高保真？建议是，但必须方向差大；锁定后再生 Style Bible 和量产图。
