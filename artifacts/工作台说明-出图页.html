3. 右侧双时间线

图版本 Tab

  • 列表：当前槽下全部 ImageRev，按时间倒序
  • 字段：thumb / vN / action_type / 一句话 diff / adopted 标记
  • 点击 = 预览；「设为当前采用」= 改 adopted_image_id

风格版本 Tab

  • 列表：当前风格线下全部 StyleRev
  • 字段：bible 缩略 / revN / change_log / current 标记
  • 「设为当前」只移动 current_rev
  • 图条目旁标注「生成于 revX」，用来解释漂在哪一版

两条时间线禁止混成一条。回退不做整项目一键回到上周。

4. 微调双出口

出口默认请求留下什么确认文案
只改此图（主按钮） 是 POST /tune {image_id, edit_scope, params, writeback:none} insert ImageRev，parent=当前图。下一张新图不带这次修改。 无需二次确认
写回风格（次按钮） 否 writeback:promote → insert ImageRev + insert StyleRev 风格升一版。旧图保留。默认不重出整个图集。 「会影响这条线以后出的新图，已采用的图不会自动变。」

P0 动作：更像风格卡 / 更干净 / 换构图 / 明暗冷暖对比饱和质地滑杆 / 一句局部指令。滑杆换了材质或密度家族、或连续两张都改同一轴 → 提示改走写回，不自动写回。

editing 时：中栏必须钉住改前对照；底栏「出 2 张」禁用，避免和「改这张」抢提交。

8. 空状态与危险操作

  • 刚从段 1 进入：中栏是界面预告 + KV 预告；图版本只有「锁定预览 · v0」；三槽显示未出图。
  • 某槽未出图：虚线框「出一张」；文案「选物料槽，填一句内容」。
  • 备选为 0：显示「还可再开 2 条」，点击回段 1，不在本页开 4 宫格。
  • 切走风格线时，未采用的微调稿留在原线的图版本里，不跟着带走。
  • 归档当前工作线前，必须先指定另一条顶上。
  • 删除 = 归档，不是真删。

9. 这一页不要出现

图层 / 笔刷 / 自由 prompt 大框 / 整项目一键回滚 / 两条风格同时出图 / 微调里改色号与字体文件 / 把「再生成」做成唯一按钮。

信息层级：顶栏 = 我在改哪一层 · 左栏 = 这条线长什么样 · 中栏 = 这一张图 · 右栏 = 从哪来、回哪去 · 底栏 = 下一张出什么。
关联需求：PRD v0.2 主流程 · v0.3 版本 / 多风格 / 微调。
